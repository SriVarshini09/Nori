# Demo script (3 minutes)

Warm state before the slot: `npm run demo`, `npm run web`, `npm run companion` running; seed loaded with your real resume; Cline key saved in Settings; Slack (or Telegram) linked; one application already waiting for approval; Google Sheet open in a tab; a recruiter-style email drafted in a second mailbox ready to send.

## 0:00 The line
"Everyone's shipping closed personal agents. This one is open: open models through Cline, your own data in a graph you can export, and it applies honestly because it cannot invent a claim."

## 0:15 Phone or companion
Click the companion in the menu bar. Show the morning brief: found, applied, skipped with reasons, waiting on you. Say: "This is what runs while I sleep."

## 0:40 Discovery with Parallel
In chat: "find staff frontend roles at Series B companies, remote". Parallel Search and Extract bring back roles; the research card shows stage, funding, recent news, with citations from the Task API. Say: "live web, cited."

## 1:10 The graph and the diff
Open the top role. Match explanation: matched requirements with the graph node that proves each, missing ones. Click Apply. Show the resume diff: before, after, why, and the node each change came from. ATS score. Say: "every line traces back; this is the part other tools fake."

## 1:45 The form, filled
Approve. The driver fills the real Greenhouse form in dry run: screenshot, every field listed, essay answers written by the agent in plain language from the graph. Open the Sheet: the row appeared through Composio. Say: "nothing is sent until I say so."

## 2:15 The inbox loop
Send the prepared recruiter email to the connected Gmail. Within the poll, the tracker row flips to Replied, a calendar hold appears, and a drafted reply is in Gmail drafts. Say: "Gmail, Sheets and Calendar through Composio; I never left the chat."

## 2:40 Cline drives it
In Cline: "use jobgraph to find roles and tailor for the top one." The MCP tools run. Show `cline schedule` for the daily tick. Say: "built with Cline, driven by Cline, scheduled by Cline."

## 2:55 Close
"Open source, MIT, runs on your own box with Ollama. Repo link is in the chat."

## Fallbacks
- Wifi down: play the recorded video of this exact script.
- Parallel slow: the research card from the warm state is already cached; narrate instead of waiting.
- Form fill slow: the application already waiting at form review shows the same screen.
